# 엔터프라이즈 전환 작업 계획서 (실행안 v1.0)

- 기준일: 2026-02-12
- 실행 기간: 2026-02-16 ~ 2026-06-19 (9개 스프린트, 2주 단위)
- 목적: 팀 칸반 도구를 사내 표준 엔터프라이즈 PM 플랫폼으로 전환

## 1. 목표와 완료 기준

1. 사내 표준 프로젝트 관리 도구로 운영 가능 상태 도달
2. 품질 게이트 통과: `lint/test/build` 모두 CI Green
3. 보안 게이트 통과: SSO+MFA, 권한 정책 강제, 감사로그 추적 가능
4. 제품 게이트 통과: Jira 핵심 대체 기능(Epic/Story/Subtask, Sprint, Workflow, Automation)

### 핵심 KPI

| 구분 | 목표 |
|---|---|
| CI 성공률 | 95% 이상 |
| 테스트 통과율 | 100% |
| API p95 | 300ms 이하(핵심 조회) |
| 고심각도 취약점 | 0건 |
| 파일럿 팀 만족도 | 4.2/5 이상 |
